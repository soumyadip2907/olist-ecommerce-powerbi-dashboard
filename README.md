# Olist E-Commerce Power BI Dashboard



## Project Overview



An interactive Power BI dashboard built to analyze the Olist Brazilian e-commerce dataset and provide business insights across sales, customers, sellers, and operations.



The project transforms raw e-commerce data into an interactive two-page analytical dashboard designed for business reporting and decision-making.



## Dashboard Pages



### 1. Executive Overview



Provides a high-level view of overall e-commerce performance, including:



- Revenue and order KPIs

- Customer and seller metrics

- Average Order Value

- Revenue and order trends

- Order status distribution

- Revenue by product category

- Orders by Brazilian state

- Payment method analysis

- Period-over-period performance comparisons



### 2. Customer, Seller \& Operations Analysis



Focuses on customer behavior and operational performance, including:



- Customer segmentation

- Customer growth trends

- Customers by Brazilian state

- Average delivery time

- Review score distribution

- Review score vs. delivery time analysis

- Seller-level performance analysis
